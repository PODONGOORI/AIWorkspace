# ppt_html: 보고서형 HTML 슬라이드 양식

이 스킬은 **겉모습만** 정한다. 무엇을 쓸지(내용·논리·교수법)는 사용자나 다른 스킬이 정하고, 이 스킬은 그 내용을 아래 양식에 꽉 차게 담는다.

## 만드는 순서
1. `assets/template.html`을 새 파일로 복사한다. 템플릿에는 CSS 전체, MathJax 설정, 탭·쪽번호·여백 채우기·축소·발표 모드 스크립트, 그림 도우미(`window.PPT`)가 이미 들어 있다. 스타일을 새로 짜지 말고 이 클래스들을 쓴다.
2. 예시 슬라이드(표지, 목차, 기본형, 탭형)를 지우거나 고쳐 내용을 채운다. 부품과 HTML 조각은 `references/components.md`, 색은 `references/palette.md`를 본다.
3. 그림은 스크립트의 `/* ===== 덱별 그림은 여기에 ===== */` 자리에 `PPT.graph(...)` 등으로 그린다. 예시 그림(`fig1`)은 지운다.
4. `python3 scripts/inline_assets.py 덱.html`로 표지·목차 일러스트(`{{COVER_ILL}}`)를 넣는다.
5. `node scripts/check_deck.js 덱.html` (CDN이 막힌 환경이면 `--mathjax 로컬경로`)로 검사하고, 문제를 고친 뒤 PNG 몇 장을 직접 열어 본다. 아래 "검사 기준"을 통과할 때까지 반복한다.

## 양식 규칙 (왜 그런지 함께)
- **캔버스는 1280×720 고정**. 화면에 맞춰 통째로 축소되므로 px 좌표가 곧 인쇄 결과다. 슬라이드 틀(`.hd`, `.tag`, `.ins`, `.bd`, `.pg`)의 위치는 바꾸지 않는다. 장마다 틀이 같아야 넘길 때 시선이 흔들리지 않는다.
- **제목**: `01 섹션 | 주제`. 번호는 가는 남색, 섹션명은 보통, 주제만 굵게. 한 줄에 들어가게 짧게(주제 약 22자).
- **우측 상단 라벨**(`.tag`): 섹션명. 제목 오른쪽 가는 선 바로 위에 붙는다.
- **핵심 메시지 바**(`.ins`, 남색 ✓): 그 장의 결론 한 문장. 청중이 이 바만 읽어도 흐름을 따라오게 한다. 질문이나 소제목 대신 결론을 쓴다.
- **목차 장에는 핵심 메시지 바·요약 박스를 넣지 않는다.** 큰 `Contents` + 번호 목록 + 일러스트만.
- **페이지를 아래까지 채운다.** 빈 하단은 미완성처럼 보인다. 템플릿의 여백 채우기 스크립트가 남은 높이를 표 행 → 목록 글씨·간격 → 블록 간격 순으로 자동 분배하지만, 그건 마무리용이다. 60px 이상 남으면 먼저 내용을 보강하거나(그림 키우기, 표·예시 추가) 장을 합친다. 목록 간격만 벌어져 듬성듬성해 보이면 실패다.
- **밀도**: 한 장에 '그림 1개 + 두 칸(표·글머리)' 정도를 기본으로 담는다. 내용이 적은 장 두 개는 하나로 합친다. 반대로 넘치면 표를 `.c`/`.c.tight`로 줄이고, 글머리는 한 줄로 깎고, 보조 설명(`.s`)을 뺀다. 글씨를 14px 아래로 줄여서 해결하지 않는다.
- **한글 줄바꿈은 단어 단위**(`word-break:keep-all`, 템플릿에 포함). 줄 끝에 조사 한 글자만 넘어가면 문장을 고친다.
- **수식은 LaTeX**(MathJax). 인라인 `$…$`, 크게 `\[…\]`를 `.eq` 안에. 계산 숫자도 가능하면 수식으로.
- **표는 회색 머리 + 전체 격자**(`table.t`). 강조는 `td.best`(연남색) 하나만, 장마다 한두 칸.
- **그림 글자는 선·노드와 겹치지 않게**. 겹치면 그림 높이를 늘리거나 라벨을 노드 아래·그림 위아래 여백으로 옮긴다.
- **단계 설명**은 같은 그림을 장마다 반복하고 상태만 바꾼다: 이번 단계 남색 채움, 끝난 부분 회색 실선, 아직인 부분 연회색 점선. 묶음에는 왼쪽 인덱스 탭(`.tabs`)을 단다.
- **색은 남색 + 회색 단계만**(`references/palette.md`). 새 색을 들이지 않는다. 한 가지 색으로 위계가 정리되어 보고서다운 인상을 준다.

## 검사 기준 (check_deck.js 결과)
- `over`, `TITLE`, 수식 오류, 스크립트 오류: 0이어야 한다.
- `note`: 실제 글자·표가 요약 바에 가리면 고친다(빈 여백만 겹친 경우는 괜찮다).
- `gap`: 칸마다 대략 30px 이하. 60px 이상이면 채운다.
- PNG를 열어 글자 겹침, 잘린 표, 한 글자 줄넘김을 눈으로 확인한다. 측정으로는 그림 속 글자 겹침을 못 잡는다.

## 배포 메모
- 파일 첫 줄의 `<meta charset="utf-8">`은 지우지 않는다. 이게 없으면 메일 미리보기·아이패드 파일 앱처럼 UTF-8을 기본으로 가정하지 않는 곳에서 한글이 깨진다.
- 메일 첨부 미리보기(Outlook 등)는 CSS·스크립트를 제대로 실행하지 못해 배치가 겹친다. 받은 사람은 파일을 Chrome·Safari·Edge로 열어야 한다고 안내한다.
- 외부 리소스는 Google Fonts(Noto Sans KR)와 cdnjs의 MathJax 3.2.2만 쓴다. 나머지는 모두 인라인(이미지는 data URI).
- 인터넷이 없는 곳에서 열면 수식이 `$…$` 원문으로 보인다. 오프라인 배포가 필요하면 미리 알려 준다.
- 발표 모드: 툴바 버튼 또는 F 키, 방향키로 넘김, Esc로 목록 보기.
