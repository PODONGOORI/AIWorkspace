# 색 구성 (ppt_html)

국회 발표자료 PDF에서 실측한 값. 남색 하나 + 회색 단계로만 구성한다. 다른 색(빨강·초록·주황 등)을 새로 들이지 않는다. 강조가 더 필요하면 남색 채움 → 남색 테두리 → 연남색 바탕 순으로 세기를 조절한다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--navy` | `#002060` | 핵심 메시지 바(`.ins`), 섹션 번호, 표지 하단 띠, 강조 노드·화살표, 정답 셀 글자, 소제목 번호 ①② |
| `--navy2` | `#03296a` | 활성 인덱스 탭 |
| `--tint` | `#e6ebf5` | 강조 셀 바탕(`td.best`), 출발점·근거 박스 바탕 |
| `--ink` | `#262626` | 본문 |
| `--g700` | `#404040` | 슬라이드 제목, 표 위·아래 굵은 선 |
| `--g600` | `#595959` | 보조 설명(`.s`), 점선 화살표 |
| `--g500` | `#7f7f7f` | 축, 표 머리 아래선 |
| `--g400` | `#a6a6a6` | 비활성 탭 글자, 기본 화살표, 계산 끝난 부분 |
| `--g300` | `#bfbfbf` | 표 셀 선 |
| `--g200` | `#d9d9d9` | 표 머리 바탕, 구분선, 제목 오른쪽 가는 선 |
| `--g100` | `#f2f2f2` | 비활성 탭 바탕, 하단 요약 바(`.note`) |
| `--g50` | `#f8f8f8` | '아직' 상태 노드 바탕 |
| `--rail` | `#d8ded7` | 탭 옆 세로선 |
| `--muted` | `#878787` | 우측 상단 섹션 라벨, 쪽번호, 출처 |
| `--page` | `#e8eaed` | 슬라이드 바깥 배경 |

## 세기 순서 (같은 그림 안에서 중요도 표현)
1. 남색 채움 + 흰 글자: 이번 단계, 정답, 최종 결과
2. 남색 굵은 선/테두리: 선택한 화살표, 출발점
3. 연남색(`--tint`) 바탕: 강조 셀, 근거
4. 회색 실선(`--g400`): 이미 끝난 부분
5. 연회색 점선(`--g300`): 아직 오지 않은 부분, 가정

## 차트
- 계열이 둘이면 남색(주) + 회색 점선(비교/예측).
- 막대 비교는 회색(기준) → 남색(제안) → 진회색(상한).
- 범례는 그림 바로 아래 `.legend` 한 줄.
