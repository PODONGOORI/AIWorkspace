# 2-노드 계통 모델: LMP vs SMP 비교

송전선으로 연결된 **두 개의 노드**를 모델링하고, 각 노드의 **지점별 한계가격
(LMP, Locational Marginal Price)** 과 계통 전체의 단일 가격인 **계통한계가격
(SMP, System Marginal Price)** 을 비교하는 최소 예제입니다. 외부 라이브러리 없이
순수 파이썬으로 동작합니다.

```bash
python3 two_node_lmp_smp.py
```

## 계통 구성

```
          f (MW)
   [노드 1] ----||---- [노드 2]      송전 한계: |f| <= Fmax
      | 발전기 G1          | 발전기 G2
      | 부하   D1          | 부하   D2
```

- 두 노드는 무손실 송전선 1회선으로 연결 (조류 `f`: 노드1 → 노드2).
- 각 노드에는 발전기 1대와 부하 1개가 연결.
- 발전기 비용곡선: `C_i(g) = a_i·g + 0.5·b_i·g²` → 한계비용 `MC_i(g) = a_i + b_i·g`
  (`b_i = 0` 이면 한계비용이 일정한 블록형 발전기).

## SMP 와 LMP 의 정의

| 가격 | 계산 방식 | 의미 |
|------|-----------|------|
| **SMP** | **무제약(copper-plate)** 경제급전 — 송전 제약 무시 | 계통 전체 단일 한계가격. 현재 한국 CBP 시장이 에너지를 정산하는 방식 (전국 1개 가격). |
| **LMP** | **제약(DC-OPF)** 경제급전 — 송전 한계 반영 | 각 노드에서 부하 1MW를 추가 공급하는 한계비용. 노드별 가격. |

두 가격 모두 "부하를 1MW 더 공급할 때 총비용 증가분", 즉
`가격 = d(총비용)/d(부하)` 으로 계산합니다 (코드에서는 미소 섭동에 의한
유한차분). 이 방식은 어떤 발전기가 상·하한에 걸려 있어도 정확합니다.

## 핵심 결과

송전선이 **혼잡하지 않으면** 두 노드의 LMP가 같고 SMP와도 일치합니다.
송전선이 **혼잡하면** 두 노드의 LMP가 벌어지며, 단일 SMP는 이 지점별 차이를
가려버립니다.

| 시나리오 | Fmax | 혼잡 | LMP₁ | LMP₂ | SMP | 비고 |
|----------|------|------|------|------|-----|------|
| A 비혼잡 (정액 MC) | 120 MW | ✗ | 20.0 | 20.0 | 20.0 | 세 가격 모두 일치 |
| B 혼잡 (정액 MC)   | 60 MW  | ✓ | 20.0 | 50.0 | 20.0 | LMP가 분리, 혼잡지대 = 1800 $/h |
| C 혼잡 (2차 비용)  | 30 MW  | ✓ | 26.0 | 43.0 | 31.67 | SMP가 두 LMP **사이**에 위치 |

해석:

- **노드 1 (값싼 발전·수출 측)**: LMP ≤ SMP. 송전선이 막혀 값싼 전력을 더
  내보내지 못해 국지적으로 가격이 눌립니다.
- **노드 2 (비싼 발전·수입 측)**: LMP ≥ SMP. 막힌 송전선 탓에 비싼 국지
  발전기로 부하를 채워야 하므로 가격이 올라갑니다.
- **혼잡지대(congestion rent)** `= f × (LMP₂ − LMP₁)` 만큼의 차액이 계통
  운영자에게 귀속됩니다 (시나리오 B: 60 × 30 = 1800 $/h).
- 정액 한계비용(B)에서는 SMP가 한계 발전기의 비용과 같아 한쪽 LMP와 일치하지만,
  완만한 2차 비용곡선(C)에서는 양쪽 발전기가 모두 한계에 있어 **SMP가 두 LMP
  사이**에 정확히 놓입니다.

## 한국 시장 관점

한국은 현재 송전 제약을 가격에 반영하지 않는 **단일 SMP** 체계입니다. 위 모델은
혼잡이 발생할 때 단일 SMP가 (1) 수출 지역에는 과도하게 높은 가격을, (2) 수입
지역에는 과도하게 낮은 가격을 적용하여 **지역적 희소성 신호를 왜곡**함을 보여줍니다.
LMP(노드별 가격)는 이 신호를 그대로 드러내며, 발전 입지·수요반응·송전 투자에 대한
효율적 유인을 제공합니다.

## 파라미터 바꿔 보기

`two_node_lmp_smp.py` 의 `main()` 에서 `Generator(a, b, pmax)`, `Node(load)`,
`fmax` 값을 조정하면 다른 조건을 실험할 수 있습니다. `Fmax` 를 충분히 키우면
어떤 구성이든 혼잡이 사라지고 LMP = SMP 로 수렴합니다.
